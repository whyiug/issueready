# Support

IssueReady is an early-stage community project maintained on a best-effort basis.

## Questions and usage help

Before opening an issue:

1. Read the [README](README.md) and [documentation index](docs/README.md).
2. Search existing [GitHub issues](https://github.com/whyiug/issueready/issues).
3. Reduce the question to a small local example without private issue content.

Open a bug report when behavior is reproducibly incorrect. Use a feature request for a new capability or public contract. General implementation questions may use a regular issue until a dedicated discussion forum exists.

## Security

Do not use a public issue for vulnerabilities or sensitive data. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.

## Scope

The maintainers cannot provide support for unauthorized testing, public-target probing, weaponized payloads, or recovery of third-party credentials and data.
